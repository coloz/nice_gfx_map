# 05：骑行给定路线引导

演示 `RouteNavigator` 沿应用提供的四个点前进：下一航点、下一点距离、剩余距离、偏离路线与到达。模拟位置沿相同带时间戳路径运行约 35 秒；背景不是实际路网。此例不计算道路路径、转向指令或路线规划。

输入/命令：`o` 将定位向东偏移 120 米，再按恢复；`r` 清偏航开关并从起点重启引导；通用平移/缩放键有效。

期望结果：正常行驶时依次推进 waypoint，终点显示 ARR。偏移时出现 OFF；到点要求进入 25 米半径，偏航阈值为 55 米。错过 waypoint 后需要实际返回到该点附近，示例不会擅自跳过配送/骑行顺序；必要时按 r 重启验证。

真实数据接点：把 `ride.sample()` 的模拟位置换为 GNSS 数据，保留 `navigator.update()`；路线来自应用已知线路或独立路由服务，再传给 `navigator.setRoute()` 与 `mapView.setRoute()`。距离为球面近似，需按定位精度调整阈值。

依赖：ESP32/S3、NICE_GFX、ILI9341、建议 PSRAM；不需要真实 GNSS、网络或 key。
