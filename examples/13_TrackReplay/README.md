# 13：时间戳轨迹回放

使用 `TrackReplay` 对五个时间戳位置插值，演示时长 60 秒。原路线为蓝线，回放位置显示方向，已经播放的历史点形成轨迹。

命令：空格暂停/继续；`</>` 速度减半/加倍（0.25—8x）；`[/]` 后退/前进 5 秒；`r` 重播；`l` 循环切换；`v` 总览；`f` 跟随。

期望结果：暂停后播放时间不增长；倍速影响时间推进，不修改原始时间戳。seek 清已播放轨迹并从新位置继续，避免一条连线跨过跳跃区间。一次播放到末尾显示 DONE；开启循环会返回开头。

真实数据接点：把已记录的 GNSS 位置和相对时间组成 `TimedPoint[]`，首个时间戳必须 0，后续严格递增。此处沿纬度和最短经度差做线性插值，不做道路匹配、速度推断或物理运动建模。

依赖：ESP32/S3、NICE_GFX、ILI9341、建议 PSRAM；默认无网络/key。
