# 12：农业地块与模拟湿度

三个 PolygonOverlay 地块按模拟湿度分为红/黄/绿，选中地块边框加粗并显示标记。HUD 展示地块号、湿度、近似面积和灌溉模拟状态。

命令：`1/2/3` 选地块；`i` 对选中地块开始/停止模拟灌溉；`v` fit 全部地块；`h` 对选中标记执行命中检查并输出索引。

期望结果：默认湿度缓慢下降，开启模拟灌溉后选中地块湿度升高，跨阈值时填充颜色改变。选择地块会停止前一个灌溉模拟；本例不驱动继电器、水泵或真实阀门。

真实数据接点：将 moisture 更新替换为实际土壤传感器遥测，并按业务 ID 关联实际地块多边形。pump 状态应来自受控设备的实际反馈。面积是矩形边长乘积的球面近似演示，不是地籍/测绘面积。

依赖：ESP32/S3、NICE_GFX、ILI9341、建议 PSRAM；默认无网络/key/外部传感器。
