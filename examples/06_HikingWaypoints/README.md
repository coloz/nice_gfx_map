# 06：徒步航点

四个航点独立选择，高亮目标；显示当前位置到目标的球面距离与真北方位。红线连接当前位置与选中目标，`fitPoints()` 让全部航点和徒步者进入视口。

命令：`n/b` 下一个/上一个航点；`t` 模拟步行/暂停；`v` 全部总览；`f` 进入跟随。模拟步行每 500ms 最多前进 4 米，到达 3 米内停止前移。

期望结果：切换目标后方位、距离和连线改变；t 后位置逐步靠近目标，留下轨迹；手动平移可查看其他区域，v 恢复总览。

真实数据接点：用实际 GNSS 更新 `hiker`，跳过模拟步进，再使用 `distanceMeters()`、`initialBearingDegrees()` 更新 HUD。方位是真北航向，不是未校准磁力计朝向；不要据此宣称离线道路/登山路径规划。

依赖：ESP32/S3、NICE_GFX、ILI9341、建议 PSRAM。默认全部模拟，无网络/key。
