# 08：围栏状态报警

使用 `GeoFence` 判定圆形或简单多边形围栏，使用 `CircleOverlay` / `PolygonOverlay` 显示相应边界。模拟位置在边界两侧往返，并加入小幅抖动，显示 inside/outside 与 ENTER/EXIT 累计次数。

命令：`p` 圆形/多边形切换；`h` 迟滞 8m/25m 切换。重建围栏会重置统计，避免沿用另一种形状的进入状态。

期望结果：串口仅在状态转换时输出 ENTER 或 EXIT / ALARM；不是每个采样都反复报警。较大迟滞减少边界附近切换。首次采样建立状态，不应理解为已经发生一次入侵事件。

真实数据接点：用真实 GNSS 替换模拟 `position`，保留 `fence.update()`；把 entered/exited 交给自己的蜂鸣器/业务队列。不要直接用不确定定位作安全联锁。本例不操作实际报警硬件。

几何限制：简单单环多边形，无洞；绘制圆使用局部 Mercator 比例，围栏判定为球面距离，两者在演示区域接近，不是测绘精度保证。

依赖：ESP32/S3、NICE_GFX、ILI9341、建议 PSRAM；默认免网络/key。
