# 09：配送顺序停靠

四个停靠点按固定顺序处理：已完成为绿色、当前为红色、待处理为蓝色。地图展示剩余停靠路线；位置接近下一点后必须手动确认，状态不会仅因动画到点自动计为送达。

命令：`t` 模拟行驶/暂停；`c` 确认当前点；`r` 重置。确认只在下一点 25 米内接受，距离太远时屏幕显示 TOO FAR，串口说明拒绝原因。

期望结果：先按 c 会被拒绝；t 后每 400ms 最多前进 8 米，接近时停下并提示 PRESS c。确认推进到下一点，完成四点后显示 ALL DONE。

真实数据接点：实际定位替换 `courier`，停靠列表来自应用；保留 `distanceMeters()` 到点检查与显式确认。生产应加入定位精度、收货证据和持久化事务；这里不做路网规划、路线优化或服务端履约。

依赖：ESP32/S3、NICE_GFX、ILI9341、建议 PSRAM；默认免网络/key。
