# 11：天气透明叠加层

蓝/黄/红区域由代码生成，**不是天气实况或预报**。底图 RGB565 加第二层 RGB565/alpha 瓦片，共用真实 `SourceLayer.overlay` 与 `setLayerOpacity()` 合成流程；透明区能看到底图。

命令：`[/]` 每次减/加 25 全层透明度；`o` 显隐；`n` 下一合成帧。改变全层透明度保留解码缓存；切帧改变生成参数并用 `setLayer(1, ...)` 刷新天气层，使新帧重新进入正常请求/提交链路，保留底图缓存和其他图层任务。

期望结果：alpha=0 时底图仍在；增加透明度后看到彩色覆盖，半透明边缘保留底图；切帧彩色区域位置变化。标注始终显示 SYNTH，不能拿演示颜色作天气决策。

真实数据接点：将第二层 URL 改为获准的气象栅格源，确认投影、时间戳、PNG alpha、tileSize 和缓存样式版本。降雨强度颜色表、单位、图例与过期时间由业务定义；本例没有连接气象平台。

依赖：ESP32/S3、NICE_GFX、ILI9341、建议 PSRAM；过程生成默认不需要网络/key/PNGdec。
