# 07：车队监控

五个可重复模拟车辆围绕同一区域移动，业务 ID 为 101—105。普通标记蓝色，选中标记红色。选择车辆后用地图定位状态跟随该车，`fitPoints()` 用于总览。

命令：`1..5` 选车跟随；`v` 退出跟随并显示全车队；`h` 在地图中心像素 `(160,100)` 做 `markerAt()` 命中测试，容差 12px，命中则选中。可先平移把目标放到中心，串口显示命中索引；标记索引与业务 ID 分开。

期望结果：每秒五车位置变化；选车后中心随车变化，总览保留所有车辆。选车后手动平移会退出跟随，HUD 显示 SELECTED；按 f 或重新选车恢复 FOLLOW。h 命中检测使用实际 Marker 几何，不是固定返回某辆车。

真实数据接点：将 `updateFleet()` 的圆周模拟替换成服务器/MQTT/串口收到的车辆位置；在 owner task 中按业务 ID 维护数组并调用 `setMarkers()`。触摸时把屏幕坐标减去地图 y=20 的偏移，再交给 `markerAt()`。

依赖：ESP32/S3、NICE_GFX、ILI9341、建议 PSRAM；默认免网络/key。
